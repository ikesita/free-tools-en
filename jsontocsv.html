Frequently asked questions

What JSON format does the converter accept?

A JSON array of objects, such as [{“name”:“Ada”,“age”:36},{“name”:“Alan”,“age”:41}]. A single object also works — it is treated as a one-row table. The header row contains every key found in any object, in the order the keys first appear.

What happens to nested objects and arrays?

Nested objects and arrays are written into the cell as compact JSON text (for example {“x”:1} or [1,2]). CSV is a flat format, so deep structures cannot become separate columns. Null values and missing keys become empty cells.

How are commas, quotes and line breaks inside values handled?

Following the standard CSV rules (RFC 4180), any value containing the delimiter, a double quote or a line break is wrapped in double quotes, and quotes inside it are doubled. Excel, Google Sheets and other tools read the result correctly.

Is my JSON uploaded anywhere?

No. The conversion runs entirely in your browser with JavaScript. Your data never leaves your device, which makes the tool safe for exports containing personal or business data.
