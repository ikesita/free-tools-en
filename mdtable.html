Frequently asked questions

How do I use the generated table?

Copy the output and paste it into any Markdown document — a GitHub README, an issue, a wiki or a note-taking app that supports Markdown tables. The first row of your input becomes the header, and a separator row with dashes is added automatically, as Markdown requires.

What input format does it accept?

One row per line, with cells separated by commas or tabs. Tab-separated data pasted straight from Excel or Google Sheets works as-is. Quoted CSV fields that contain commas are not parsed — remove the quotes first, or use tabs. A few cells may be left empty; rows shorter than the header are padded with empty cells.

What do the alignment options change?

Alignment is written into the separator row: :--- means left, :---: means center and ---: means right. Renderers such as GitHub use it to align the column contents. The generator also pads every cell with spaces so the raw Markdown lines up in neat columns when read as plain text.

What happens to pipe characters (|) in my data?

A pipe inside a cell would break a Markdown table, so it is escaped as \| in the output, which Markdown renderers display as a plain |. Line breaks inside a cell cannot be represented in a standard Markdown table and are replaced with spaces.

Your input stays in your browser and is never sent anywhere.
