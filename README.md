# Free Online Tools & Calculators

Simple, fast, free online tools and calculators. Every tool runs entirely in your browser — your input is never uploaded to a server. From QR codes and BMI to loans, dates and unit conversions, it covers everyday calculations in English.

## 🌐 Live site

**[https://ikesita.github.io/free-tools-en/](https://ikesita.github.io/free-tools-en/)**

## Main tools

- **Everyday calculators**: QR Code Generator, BMI Calculator, Date Calculator, Loan Calculator, Percentage Calculator
- **Money**: Compound Interest Calculator, Salary Converter, Tip Calculator, VAT / Sales Tax Calculator, Discount Calculator
- **Conversions**: Unit Converter, plus converters for length, weight, volume, temperature, speed and area (kg/lbs, km/miles, °C/°F, sq ft/sqm and more)
- **Dates & time**: Days Until, Add Days, Age in Days, Business Days, Time Zone Converter, Countdown Timer & Stopwatch
- **Text & developer tools**: Word Counter, Text Case Converter, JSON to CSV, CSV to JSON, Slug Generator, UUID Generator, Number Base Converter, HTML Entities, Markdown Table Generator
- **Fun & handy**: Random Number Generator, Coin Flip, Roman Numeral Converter, Square Footage Calculator, Password Generator

## How to use

Open the live site in your browser and pick a tool — no installation or sign-up needed.
