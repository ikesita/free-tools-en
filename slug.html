Frequently asked questions

What is a URL slug?

A slug is the readable part of a web address that identifies a page, such as “how-to-bake-bread” in example.com/blog/how-to-bake-bread. Slugs use lowercase letters, numbers and separators instead of spaces and punctuation, so the URL stays valid and easy to read and share.

Are hyphens or underscores better in slugs?

Hyphens are the common recommendation for web URLs: search engines treat a hyphen as a word separator, while an underscore is treated as joining the words into one. This tool offers both, since some file systems and wikis prefer underscores.

What happens to accented letters like é or ü?

Accents are removed and the base letter is kept, so “Café” becomes “cafe” and “Zürich” becomes “zurich”. Characters that cannot be converted to plain a–z or 0–9 are dropped, because standard slugs should only contain ASCII characters.

Why set a maximum length?

Short slugs are easier to read, type and share, and some CMS platforms limit URL length. If you set a limit, the slug is cut at the last whole word that fits, so it never ends mid-word or with a dangling separator.
