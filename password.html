Passwords are generated with crypto.getRandomValues, your browser's cryptographically secure random source, with rejection sampling so every character is equally likely. The strength label is a rough estimate based on length and the size of the character set (entropy ≈ length × log₂ of set size) — it says nothing about whether a password has been reused or leaked. Use a unique password per site, ideally stored in a password manager.

Your input stays in your browser and is never sent anywhere.
